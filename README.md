### 🎯 What is TraceFlow?

**TraceFlow** is a lightweight, developer-friendly **Python tracing and profiling library**. It gives you **visibility into how your code actually runs** — which functions get called, how long they take, and where the bottlenecks hide — without the overhead of heavy profilers.

### ✨ Key Features

| Feature | Description |
|---|---|
| 🧵 **Call Tracing** | Track the full call stack and execution flow of any function |
| ⏱️ **Function Profiling** | Measure execution time per function, per call |
| 🪶 **Lightweight** | Minimal overhead — safe even in development builds |
| 🧩 **Zero-boilerplate API** | Add tracing to your code with a single decorator |
| 📊 **Structured Output** | Clean, readable data ready for logging or visualization |
